# Offline design-system viewer

Open `index.html` in a browser with the complete `preview/` folder beside it. Alternatively, from the project root run `node docs/design-system/serve-preview.mjs` and open the printed address.

The viewer includes 16 Figma presentation boards, a four-screen illustrative prototype, CSS/JSON token snapshots and 14 Microsoft Fluent icons with their license. Search boards, step through them, download individual PNGs, and try the browse → details → review → save flow. Prototype fields are illustrative; no personal library is read or saved.

[Open the editable Figma design system](https://www.figma.com/design/PFC9DSki5Eyil4oRWc0x7k?node-id=12-2) · [Portfolio boards](https://www.figma.com/design/PFC9DSki5Eyil4oRWc0x7k?node-id=13-11) · [Figma prototype](https://www.figma.com/proto/PFC9DSki5Eyil4oRWc0x7k?node-id=10-40&starting-point-node-id=10%3A40)

These are reference exports. The editable components and variables remain in Figma; no native `.fig` file is included. Figma access follows the file owner’s sharing settings. Read [handoff notes](FIGMA-HANDOFF.md) for scope and verification limits.
